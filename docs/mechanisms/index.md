# 核心机制详解

本目录解释 `agent-stack` 在运行时的核心机制，补充根 [ARCHITECTURE.md](../../ARCHITECTURE.md) 的系统地图。

## 内容约定

每篇机制文档聚焦一条真实存在的运行时链路，按以下顺序组织：

1. **运行入口与装配**：请求或任务从何处进入，由谁负责构图或派发。
2. **状态与事实 Owner**：核心状态保存在哪里，事务边界与读写分工如何划分。
3. **权限与隔离**：访问控制、路径或沙箱边界在何处最终执行。
4. **失败与恢复**：中断、超时、取消与重试如何收敛。
5. **源码与验证入口**：直接链接拥有当前行为的模块与测试目录。

## 专题范围

仅在某个机制具备稳定 Owner、真实链路与明确维护价值时按需建页；未实现的设计提案请放入 [decisions/proposed/](../develop-guides/decisions/README.md)，本地临时推演放入 `docs/vibe/`。
