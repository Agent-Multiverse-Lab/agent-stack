# 知识库工作区实施计划

## 当前任务与目标

在 LayerFS `knowledge-workspace` 分支补齐知识库工作区，提供文件组织、持久批任务、设置和检索评估。

## 如何修改

沿用现有知识服务、解析流水线、模型绑定和 React/shadcn 组件。新增配置、文件夹和任务的 PostgreSQL 持久化；ARQ 执行批处理与检索评估。

界面采用 168px 文件夹侧栏、文件表格和右侧预览；顶部集中检索、图谱、评估、任务入口。
沿用系统字体、15px 正文与现有 token：主色 #046a82、悬停 #24839a、画布 #ffffff、正文 #1e1f1f、次要文字 #697070、边框 #eef0f0。

## 实施步骤

1. 保存知识库切块、模型和检索配置，接入实际索引与查询。
2. 增加目录、文件移动与重命名、原文件下载、批处理与进度记录。
3. 复用检索评估器执行人工标注数据集，保存逐问题结果与质量报告。
4. 完成页面交互、后端行为测试、前端检查与构建。

## 验收标准

- 文件能够按目录上传、浏览、移动与重命名，原文件可下载，解析内容可预览。
- 批处理逐文件记录结果，页面关闭后继续执行，任务页可查看进度和失败原因。
- 已建立索引的 Embedding 绑定不被设置覆盖。
- 检索评估使用实际查询接口；报告提供命中率、精确率、召回率、F1 和逐问题结果。
- 不同用户、知识库的目录、文件、任务互不串用。
