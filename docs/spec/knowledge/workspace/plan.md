# 知识库工作区实施计划

## 当前任务与目标

在 `feat/knowledge-workspace` 分支补齐知识库前后端操作闭环，使用本项目命名与 React 组件。

## 如何修改

沿用现有知识服务、解析流水线和向量绑定；在所属 repository 承载新增持久化，
通过独立知识任务服务与 Worker 函数承接批处理。现有页面增加目录、设置与评估入口。

## 实施步骤

1. 配置与文件组织：模型迁移、设置校验、目录和文件操作接口。
2. 处理与检索：保存的参数接入解析、索引和检索；持久化批任务及逐文件结果。
3. 操作界面：知识库设置、目录与批处理、下载、检索参数、评估报告。
4. 验证：后端行为测试、前端交互测试、类型检查、lint、构建与页面检查。

## 验收标准

- 文件能完成上传、解析、索引、检索与来源预览。
- 设置保存后实际影响后续处理与查询；已有向量模型绑定不被覆盖。
- 批量失败可定位到文件，其他文件结果保留；进度不依赖浏览器连接。
- 不同用户、知识库之间的数据互不串用。
- 新增源码、页面文字和文档使用当前项目名称。
