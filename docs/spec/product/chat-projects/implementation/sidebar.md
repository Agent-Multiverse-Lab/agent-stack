# 侧栏交互与同步

## 当前任务

CP-05 至 CP-06：将项目和置顶能力接入桌面侧栏。

## 实现

- Project API 独立放在 `api/project.ts`，Thread API 增加归属、置顶字段和通用更新方法。
- `AppSidebar` 保存项目列表、展开项目和刷新版本；操作完成后统一刷新。项目请求在组件卸载或被新请求替代后不回写旧结果。
- `NavPinned` 展示置顶项目与置顶会话；`NavProjectList` 管理项目及展开列表；`NavProjects` 复用分页与会话操作，按三个区域传入对应筛选条件。
- 沿用现有侧栏间距、字号、语义颜色、shadcn/ui 菜单及确认弹窗；文案提供英文和中文。
- 删除项目确认说明会话保留；提交期间禁用重复操作，失败就地显示错误。

## 验收

- 新建、重命名、删除项目；删除后会话返回未归组列表。
- 会话移入和移出项目后两个区域同步。
- 项目与会话置顶、直接取消置顶、重新挂载后从 API 恢复状态。
- API 失败时显示错误并保留原会话；无置顶条目时隐藏 Pinned 区域。
