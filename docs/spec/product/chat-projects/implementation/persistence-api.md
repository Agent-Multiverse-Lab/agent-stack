# 持久化与 HTTP 合同

## 当前任务

CP-01 至 CP-04：持久化项目、会话归属与置顶，并提供按用户隔离的 API。

## 实现

- `0030_project_and_pinned` 创建 Project 表、会话可空外键与置顶时间；升级后已有会话保持未归组、未置顶。
- `ProjectRepository` 负责按用户读取、排序、更新及软删除解绑；Service 使用现有请求事务。绑定和删除获取同一 Project 行锁。
- 创建会话时验证项目所属用户；更新会话依据 `model_fields_set` 区分省略与显式 null。目标会话继续由 `get_top_level_for_user` 校验。
- 顶层会话列表在 SQL 层处理指定项目、未归组和置顶筛选；排序与游标共同使用置顶时间、活跃时间、ID。游标版本更新为 2。

## 验收

- CRUD、用户隔离、已删除项目拒绝绑定、显式解绑、置顶切换、删除事务回滚。
- 多条相同置顶时间和活跃时间的会话连续分页不遗漏、不重复，能跨过置顶与未置顶边界。
- 迁移升级与降级保留已有会话内容。
