# docs/spec 索引

`docs/spec` 按能力分成：

- `run/`：运行域（生命周期 / 取消 / 事件流）
- `agent/`：代理域（上下文管理 / 子代理委派）
- `knowledge/`：知识域（输入处理 / 检索 / 评估）
- `persistence/`：持久化边界
- `product/`：产品身份与跨页面体验

每个能力目录应包含：

1. `spec.md`：行为要求与验收标准  
2. `plan.md`：实施步骤与接口映射  
3. `tasks.md`：可执行任务清单
